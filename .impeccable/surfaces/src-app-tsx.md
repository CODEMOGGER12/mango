# Surface: MANGO storefront (single page)

Scope: the whole one-page store at src/App.tsx. Visitor mode: Persuade. Audience: general online shoppers. Action: pick a color, add to cart, place an order request (no payment). Proof: the 3D object itself, turnable, in ten colors. Constraints: ¥12 for every variation; no invented specs, reviews, or customers. Direction pinned by the user's reference recording (dialedcoffee.com structure), so no concept-seed roll was run; build path code-led (no harness image generation).

## Direction contract

THESIS: The clay object is the page's only image. A store where the product, rendered live, does every job photography usually does. Refuses the category default of a product-card grid on a pastel gradient.

OWN-WORLD: Warm studio-gray ground (#E4DFD7) and soft brown-black ink. Each colorway owns whole drenched regions: the color run turns the full viewport into the clay color. Schibsted Grotesk set huge and tight for headlines; Young Serif for the soft editorial voice; hairline rules; square edges; no cards, no shadows on UI.

STORY: See the object; turn it; watch it run through ten colors; choose one; learn it is imperfect on purpose; add to cart; request the order.

FIRST VIEWPORT: Centered MANGO wordmark nav with Shop/Colors left and About/Cart (n) right. "PLAY TAKES / SHAPE." spans the full width. The live clay object sits in front of the type, bottom-center, large. Supporting line plus "Explore the colors →" bottom-left; floating buy widget bottom-right (color, ¥12, add).

FORM: Editorial product scroll after the reference; pinned by brief, position n/a; seed key: none (pinned direction).

SIGNATURE: The color run: a pinned, drenched viewport where scrolling swaps the whole page through ten colorways while the object re-colors and turns.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
